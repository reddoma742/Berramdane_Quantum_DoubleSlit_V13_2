## ✨ Key Features  
- **Relativistic de Broglie wavelength** (full correction)  
- **Feynman path integral** (50 paths per slit, exact diffraction)  
- **Lindblad decoherence**: which‑path, thermal phonons, vacuum fluctuations  
- **Realistic detector**: Johnson‑Nyquist noise, dark counts, efficiency  
- **Speculative philosophical layer** (Berramdane spiral search) – can be disabled  
- **Complementarity plot** (V²+K² ≤ 1)  
- **Multi‑slit support** (up to 5 slits)  
- **CSV export** for further analysis
